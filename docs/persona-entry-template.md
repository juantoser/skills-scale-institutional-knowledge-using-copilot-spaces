# Persona Entry Template

Use this template to create or extend persona entries in the OctoAcme docs. Place completed entries in docs/ and link from docs/octoacme-roles-and-personas.md.

- Role name:
- Role summary (1-2 sentences):
- Responsibilities (bulleted):
- Typical communication cadence (meetings/notes):
- Key handoffs (what they deliver and to whom):
- Example acceptance criteria / success signals:
- Onboarding checklist for the role (what access/artifacts they need):
- Escalation guidance (who to contact and when):

## Handoff checklist (use when creating cross-team stories)
- [ ] Documented acceptance criteria including non-functional requirements
- [ ] Design or API contracts shared and reviewed
- [ ] Test plan or QA checklist attached
- [ ] Release/rollout plan and rollback steps documented
- [ ] Monitoring and dashboards assigned
- [ ] Support contacts and runbooks identified

## Quick guidance for maintainers
- Keep persona entries concise and action-oriented.
- Link to other process docs (release, security, incident runbooks) when relevant.

# OctoAcme Project Management Docs

This README provides a short overview of OctoAcme's project management processes and direct links to the full process documents in this folder.

## Summary
OctoAcme relies on a lightweight, iterative project management approach: validate with a short Project One-pager (Initiation), build an actionable plan (Planning), deliver in small increments with clear acceptance criteria (Execution & Tracking), manage risks and stakeholder communication (Risks & Communication), standardize Release & Deployment, and continuously improve through Retrospectives. Roles and responsibilities are documented in Roles & Personas.

- [Project Initiation Guide](./octoacme-project-initiation.md) — one-pager template, initiation checklist, decision gate
- [Project Planning](./octoacme-project-planning.md) — backlog template, planning checklist, risk capture

- [Retrospective & Continuous Improvement](./octoacme-retrospective-and-continuous-improvement.md) — retrospective structure and action item tracking
- [Roles & Personas](./octoacme-roles-and-personas.md) — role summaries and responsibilities
